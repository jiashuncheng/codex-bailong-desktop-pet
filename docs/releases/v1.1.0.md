## 下载和升级

这是**累计程序补丁**，包含此前程序更新，只需最新一份，无需逐个安装旧补丁。已有有效动画继续复用，本次不下载或重新上传动画资源。

- 已安装用户：优先使用软件内更新。
- 手动升级或首次安装：下载 **程序补丁安装器 1.1.0**（`windows-x64.zip`），解压运行“一键部署.exe”。不含动画，新用户可先使用卡片，再在设置中下载人物素材。
- `program.zip` 和 `program.json` 供软件内更新，不要手动覆盖安装目录。

已有设置、聊天、Token 数据、高清偏好和回退版本保留。升级不会自动迁移真实目录；设置、聊天和统计数据仍在原用户数据目录。程序和动画迁移均需用户主动选择目标并确认。

## 验证与平台

本地完整回归 974 项通过，另核对公开版冻结模块、TLS、原生交互、程序和安装器摘要及下载入口。目录迁移已做隔离复制、校验、失败恢复和跨盘检查；没有自动搬动真实用户目录来代替隔离验收。

本次包体适用于 Windows x64。Linux 和 macOS 由社区作者独立维护，入口见[仓库首页](https://github.com/Wunsch2048/codex-bailong-desktop-pet#社区版本)。WSL 接入沿用 1.0.1，真实发行版联调仍需用户反馈。

已知边界：Windows 切换不同 Codex 数据目录时，完成提醒和本地重置状态仍可能沿用旧目录的记录；本版尚未补齐这部分来源隔离。Token 索引已按来源分别保存。
