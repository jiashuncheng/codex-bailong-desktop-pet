# v1.1.1 程序补丁包

这是累计程序补丁包，面向已经安装白龙桌宠增强版的 Windows x64 用户。

## 修复

- 修复长时间未打开后展开大卡片、数据面板以及胶囊展开正常卡片时，目标位置提前露出完整界面的闪帧。
- 修复自动台词和点击台词被 Codex 会话状态覆盖的问题。台词结束后恢复最新会话状态，未读完成提醒不会被误清除。
- 保留 5 秒状态间隔的保存逻辑，并通过重启后的隔离验证。

## 下载

`bailong-desktop-pet-1.1.1-program.zip` 是累计程序补丁，不含桌宠动画素材。`program.json` 和 `SHA256SUMS.txt` 用于内置更新和手动校验。

补丁来自 [jingh12312-rgb/bailong-desktop-pet](https://github.com/jingh12312-rgb/bailong-desktop-pet) 的增强版本。
