# Windows / Mac 共用源码

当前版本 v0.9.4 / UI83。已合入上游 v0.9.3 及构建修复（76a2ee3），保留 Windows 个性化代码和 Mac 适配，包括会话轮换、SSH 名称、随机点击动作和焦点修复。新增水球状态动画、统一字体、闲聊可靠性改进与六类设置页。

## 首次使用

安装 Python 3.12 或 3.13；源码同步另需 Git。克隆个人 fork，使用两端共同维护的 main 分支：

```bash
git clone https://github.com/jiashuncheng/codex-bailong-desktop-pet.git
```

Windows 双击“一键启动.cmd”，Mac 双击“一键启动.command”。启动脚本自动创建本机 .venv 并安装 requirements-source.txt，不需要打包 EXE。Git 工作副本和 .venv 各机器独立保存。

首次没有动画时，选择已有完整高清素材目录，其下应直接包含素材清单.json 和 quality-v1 等子目录。可选择旧源码的 materials/hd/内容ID，或匹配的已下载高清包。素材地址沿用 app/material_catalog.json 指定的上游资源源；逐文件校验。现有完整高清缓存可复用。

本地素材补齐后运行“更新本地高清素材”，会重新校验、生成独立快照并重启。已有完整轻量素材时，也可导入部分高清，缺失文件使用轻量。全部补齐后自动使用完整高清缓存。源目录继续同步不会改动正在播放的快照。

## 日常修改与同步

1. 任一电脑修改源码，本机检查后提交并推送到个人 fork 的同一分支。
2. 另一台双击“同步更新源码.cmd”或“.command”。脚本确认无未提交修改、远程为个人 fork、更新可快进后才应用，并正常重启。依赖变化会自动补装。
3. 工作区有修改或分支历史分叉时停止同步，提示先提交或合并；不会自动 reset、删文件或丢弃修改。

源码入口为 run_source.py；两端共用 app。mac_*.py 处理 Mac 窗口、钥匙串、辅助功能和应用发现；Windows 原生分支保留。requirements-source.txt 用平台标记隔离依赖。requirements-enhanced.txt 仍用于原 Windows 冻结构建，需要单独验证。

Windows 用户数据：%LOCALAPPDATA%/BailongEnhanced。Mac 用户数据：~/Library/Application Support/BailongMac。环境、日志、聊天、统计、密钥和 SSH 配置不通过 Git 同步。已有 portable-materials.json 时仍支持程序目录 materials 模式，此本机标记不提交。

SSH：设置 → 连接与数据 → SSH 远程会话。每台电脑使用自己的 SSH 别名和认证；远端 Linux 需要 python3，无需安装守护服务。只回传状态，不冒充远端 Token 用量。

Mac 人物和普通状态卡片不取得键盘焦点，主动打开设置/聊天才接受输入。登录自启、钥匙串和视频辅助功能适配保留。“随 Codex 启动 / 退出”监听目前仅支持 Windows，Mac 控件禁用并说明限制，Mac 可使用登录启动。

## 获取上游更新

个人 fork 用于日常开发同步。需要上游功能时先 fetch 并比较，再合并到个人分支并验证两端；不要用上游安装器覆盖个性化源码。源码维护页使用源码更新流程。

## 检查

```bash
python tools/check_source.py --without-assets
python tools/check_source.py --require-assets
```

第一条运行不依赖外部动画的代码及合成数据检查；第二条额外校验全部轻量素材并运行需要动画的界面回归。Mac 原生窗口另用隔离数据运行 tools/mac_ui_probe.py 和 mac_focus_probe.py。

CI 同时运行 Windows、macOS 源码检查；冻结安装器沿用 Windows 独立检查。合成测试不等同于 Windows 实机、真实浏览器视频或远程服务器验收。
