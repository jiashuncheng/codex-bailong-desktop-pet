# 白龙桌宠增强版 v0.9.9

这次公开版汇集 v0.9.4 至 v0.9.9 的本地改动，提供 Windows x64 完整安装包及程序更新包。

## 本次重点

- 任务结束后，同一回合稍后读到的日志不会把状态重新改成“进行中”，也不会把中断或失败误改为完成；新的回合仍可正常开始。修复对应 [Issue #3](https://github.com/Wunsch2048/codex-bailong-desktop-pet/issues/3)。
- 旧 Token 数据库暂时被占用或不可读时，历史迁移会保留待重试状态，不再永久标记为完成。统计会提示数据可能不完整，下一次刷新继续尝试。修复对应 [Issue #4](https://github.com/Wunsch2048/codex-bailong-desktop-pet/issues/4)。
- Codex 在编辑消息后产生的会话分支日志映射回原对话，不再在卡片上生成无法跳转的重复条目；恢复时清理没有回合编号、无法自动确认的旧提醒。
- 极简额度圆可临时展开正常卡片，收起后仍回到极简模式；圆缩小至 54px。胶囊和极简额度圆沿用原有浅色背景、环线颜色与 Chakra Petch 字体，只增加进场填充动画。会话名与状态文字统一为 12px。
- 自主走动围绕用户手动放置的位置选择较近目标，默认仅水平移动，减少遮挡工作区；可在人物设置调整。
- 进行中状态图标改为穿插与快转交替，待机时缓慢旋转；修复静置时偶发卡顿和持续工作动作中道具反复开合。隐藏及窗口过渡期间停止多余重绘。

## 安装与已知反馈

首次安装使用完整 Windows ZIP；已有支持程序小包的版本可在软件内更新。程序更新包不重复携带角色动画，安装时会校验本机素材。安装、更新和回退均保留用户设置与数据备份。

已有用户反馈卡巴斯基在 Windows 11 上拦截旧版安装包，见 [Issue #1](https://github.com/Wunsch2048/codex-bailong-desktop-pet/issues/1)。目前没有检测名称、命中文件或报告，不能判断原因，也不把它列为已修复。发布资产附 SHA-256 校验清单；如果遇到拦截，请保留检测名称和文件哈希以便排查。

本版仍是 Windows 程序。Linux 支持请求见 [Issue #2](https://github.com/Wunsch2048/codex-bailong-desktop-pet/issues/2)；macOS 移植提议见 [Issue #5](https://github.com/Wunsch2048/codex-bailong-desktop-pet/issues/5)，目前尚未合入。
