Windows x64 快速部署

首次安装：从 https://github.com/Wunsch2048/codex-bailong-desktop-pet/releases/tag/v1.1.0 下载程序补丁安装器 windows-x64.zip，完整解压后运行“一键部署.exe”。该安装器不含人物动画。
安装后：在设置的更新与维护中检查并安装最新程序补丁。程序补丁为累计包，只需最新一份；不能把 program.zip 当成安装器或直接覆盖旧目录。
人物动画：在设置的角色与素材中下载轻量或高清资源。已有有效素材继续复用，仅卡片用户无需下载。
迁移：通过程序位置与安装管理选择新目录；不要手动移动 versions。新版本确认就绪后才切换入口，失败保留原目录。
数据：设置、聊天和 Token 统计保留在当前 Windows 用户数据目录，程序升级不携带他人的账户或密钥。
社区平台入口见仓库首页，主仓库包适用于 Windows。
原项目来源：https://github.com/jingh12312-rgb/bailong-desktop-pet
