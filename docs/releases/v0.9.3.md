# v0.9.3 / UI82 — 水球状态动画与浅色卡片适配

本次发布将此前本地实装的 v0.9.0—v0.9.3 更新合并提供，包含完整 Windows 安装包与应用内程序更新包。

## 状态图标动画

进行中状态由三颗有序水球组成：整体绕中心旋转，圆球交错换位，短暂黏连后分开；每轮更换黏连组合。完成、等待、中断、未连接和待命状态采用各自清晰的符号。完成提醒继续停留，直到用户确认。

正常浅色卡片采用更深、更清楚的紫灰与薄荷色，深色胶囊使用适配深底的亮色。状态轮廓和颜色在同一控件内平滑变形，隐藏或静止时不会持续重绘。

![浅色正常卡片与深色胶囊中的 Codex 状态图标连续动画](https://github.com/Wunsch2048/codex-bailong-desktop-pet/releases/download/v0.9.3/status-liquid-0.9.3.gif)

动图来自实装 Qt 控件的连续帧，覆盖进行中、完成确认、等待与中断等状态，并同时展示浅色卡片和深色胶囊。它用于观察控件动画衔接，不代表物理显示器的帧率测量。

## 其他更新

- **持续工作动画更自然**：笔记本开合只在动作进入阶段发生，循环期间保持道具稳定；状态变化后保留必要的收尾与切换空间，避免动作被高频状态更新打断。
- **卡片字体统一**：中文使用随程序携带的 Noto Sans SC Medium；英文和数字使用 Chakra Petch 的真实字重，改善小字、数字与日期的可读性。
- **闲聊配置更可靠**：修正配置保存、服务校验与不同响应格式识别，并给出可操作的错误提示。
- **程序内更新**：同时提供完整 Windows 安装 ZIP 和供已支持客户端使用的程序更新 ZIP/JSON；程序小包不含角色动画素材，素材仍按现有独立校验流程维护。

## 验收与安装

本机 v0.9.3 已安装运行，保留 v0.9.2 回退及用户数据备份。构建前本地完成 81 个模块、859 项回归，82 个模块编译核验，冻结 TLS 验收与 1.0、1.25、1.5、2.0 倍原生交互核验。GitHub Actions 的公开源码检查结果以本次提交对应的工作流记录为准。

- 已安装支持程序小包的版本：可从设置中的“软件更新”下载更新；旧版本如未显示小包更新，请先用完整 ZIP 升级。
