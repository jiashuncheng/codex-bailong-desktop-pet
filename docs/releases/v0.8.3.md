## v0.8.3

- 胶囊快捷按钮可自定义为 GPT 网页、Codex、闲聊、日报、刷新、设置或网址；新增可选 Codex 桌面端启动联动。
- 额外重置卡片采用统一紫灰信息层级，突出预计剩余时间；公告未确认时不会把到期误判为额度已经到账。
- 额外重置倒计时使用小时与分钟显示；整小时保留 `00` 分，不足一分钟显示 `<1分钟`，到期继续等待公告确认。
- 倒计时每分钟原位更新，详情卡片大小保持稳定；右上角新增公告网站快捷入口，点击时间仍打开桌面端详情。
- 修复会话“待查看”提醒在用户已看过 Codex 回复后仍不消失的问题。按具体已结束轮次匹配稳定的已读证据，保留其他未读会话和正在运行的会话提醒。
- 发布验证包含 739 项本地回归、81 个 Python 模块编译核验，以及 1x、1.25x、1.5x、2x 缩放下的原生交互和布局验收。

首次安装或从 v0.7.9 及更早版本升级，请使用完整 Windows 包。程序小包仅供支持该机制的已安装版本使用；动画素材仍独立校验和更新。
