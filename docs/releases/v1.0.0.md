# 白龙桌宠增强版 v1.0.0

本次公开版承接 GitHub 上一稳定版 v0.9.9，汇总此前本机迭代后落地的功能。公开版本号按 GitHub 上一稳定版递增，本机版本号独立维护。

## 更新内容

- 桌宠自主移动加入落地衔接，水平活动范围可延伸到屏幕边缘，并减少在屏幕中间停留；人物设置可调整活动范围。
- 数据面板加入历史“额度对比”：查看已用 Token 和按额度百分比推测的周期可用总量；套餐切换、数据不足和周期回填会被区分，避免把 Pro 与 Plus 的差异误报成额度缩水。
- 设置控件与数据面板导航重新整理，时间筛选使用同组滑动选择；数值输入、悬停反馈和面板切换更清楚，移除影响观感的固定按钮描边并改善展开闪烁。
- 支持仅安装卡片，也可以在设置中下载轻量或高清动画；已有动画的用户可确认移除动画而保留卡片、配置与历史数据。
- 首次安装、完整更新、程序小包和角色动画资源分开提供。完整包用于首次安装和回退；兼容客户端可使用程序更新包；仅卡片包无需先下载动画。

## 发布文件

- `bailong-desktop-pet-1.0.0-windows-x64.zip`：完整 Windows x64 安装包。
- `bailong-desktop-pet-1.0.0-program.zip` 与 `.json`：供应用内更新器使用。
- `bailong-desktop-pet-1.0.0-cards-windows-x64.zip`：仅卡片安装包。
- 轻量动画以独立素材资源发布，安装后可在设置中下载启用。
- `SHA256SUMS.txt`：安装包与程序更新文件校验值。

仅卡片安装包和动画资源是分开的下载项。需要角色动画时，先安装卡片，再从设置下载资源。首次安装建议使用完整 Windows 包。
