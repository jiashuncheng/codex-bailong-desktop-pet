## v0.7.9｜更轻、更流畅，持续跟随 Codex

本次整合 v0.7.3—v0.7.9 的更新：

- **性能优化**：减少重复动画解码，切换动作时后台释放旧解码器；使用高精度帧时钟，降低空闲轮询和写盘。固定高清测试中，CPU 耗时减少约 19%—22%，采样峰值内存减少约 60 MiB，动画计时唤醒减少约 57%；实际收益随机器和场景变化。
- **持续状态动画**：思考、阅读和执行任务采用原动作进入、正向中段循环与自然收尾；随机变化更自然，完成提醒即时显示。
- **独立卡片与极简模式**：可隐藏人物，仅保留卡片；新增仅显示额度百分比的极简模式。
- **交互修复**：改善高 DPI 点击、拖拽和鼠标捕获恢复；修复胶囊、详情与日报联动切换时的闪烁和跳位。
- **轻量默认、高清可选**：安装包默认提供 512px 轻量素材；设置 → 角色与动作 → 内置白龙画质，可下载并切换 720px 高清，画质选择随升级保留。
- **程序更新小包**：新版本支持优先下载程序包，复用校验通过的素材；不匹配时使用完整包。更新仍需主动下载安装，保留更新说明、用户数据和回退版本。

### 下载与升级

- **首次安装，或从 v0.7.2 及更早版本升级**：下载 `bailong-desktop-pet-0.7.9-windows-x64.zip`，解压运行一键部署程序；也可在旧版的“软件更新”中下载安装。本次需完整包，后续符合条件的代码更新可走小包。
- `bailong-desktop-pet-0.7.9-program.zip` 和同名 `.json` 供支持小包的内置更新器使用，**不能单独解压当作完整安装包运行**。
- 高清资源在独立素材 Release 中维护，推荐直接从设置下载。无需重启 Codex；升级会短暂重启桌宠。

验证：708 项本地回归、77 个编译模块比对、四档 DPI 原生交互、两档高清持续动作与画质切换，以及卡片/日报合成像素检查通过。定时器与合成窗口验证不等同于所有显卡和显示器帧率的保证。
