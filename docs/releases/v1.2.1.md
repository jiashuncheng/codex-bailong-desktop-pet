# 程序补丁包 1.2.1

- **远控后人物清晰度恢复**：屏幕尺寸、缩放或显示器参数改变后，重新校对动画解码尺寸，避免人物恢复大小后仍使用低分辨率画面。
- **自定义悬停提示**：顶栏四个按钮停留 0.5 秒显示简短提示，相邻按钮切换时及时更新；数据面板打开时，提示保持在其上方，不抢焦点。
- **托盘额度气泡**：悬停显示额度类型、剩余百分比和下次重置时间，沿用五小时额度优先规则。
- **共有模块连续移动**：正常卡片与详情切换时，会话、额度、Token/重置等共有内容移动到原有位置，保留当前图表进度；修复多会话文字在途中被背景盖住的问题。
- **减少切换准备开销**：复用目标快照，只整理当前可见页面的布局，减少重复绘制与隐藏页面的无用准备。不同页面仍有首次构造和系统显示等待，不宣称所有页面固定加速。
- **启动入口改进**：程序升级后的快捷方式、自启和 Codex 联动入口使用标准 Windows 快捷方式，保留原有设置。安装器本身尚未更新，本次不宣称卡巴斯基反馈已经解决。

## 下载与升级

这是**累计程序补丁**，只需最新一份，无需依次安装历史补丁。软件内更新保留已有设置、统计、素材及高清偏好；本次不上传动画资源。

- 已安装用户：在软件内检查更新。`program.zip`、`program.json` 供更新器使用，请勿手动覆盖安装目录。
- 首次安装：继续使用有效的 [1.1.0 安装器](https://github.com/Wunsch2048/codex-bailong-desktop-pet/releases/tag/v1.1.0)，安装后再在软件内更新。该旧安装器自身的启动流程不因本次补丁而改变。
- 仅卡片用户无需下载人物资源；需要时可在设置中下载轻量或高清动画。

## 验证与范围

对应开发源码通过 96 模块、1074 项完整回归；公开副本另做源码一致性、内嵌版本、冻结程序绑定、TLS、四档缩放原生交互和压缩包完整性检查。远控尺寸恢复为受控回放验证，未取得反馈者同款远控软件现场；跨驱动、多屏、休眠等场景不保证完全无闪烁。

包体适用于 Windows x64。macOS 和 Linux 由社区作者独立维护，入口见[仓库首页](https://github.com/Wunsch2048/codex-bailong-desktop-pet#社区版本)。
