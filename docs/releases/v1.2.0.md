# 程序补丁包 1.2.0

- **额度变化提醒可自定义**：周额度模块显示相对上一周期的推测总量变化，默认下降 10% 提醒、上涨 15% 提醒；下降红底、上涨绿底。套餐、模型和数据质量条件继续检查。
- **修复目录迁移失败（#15）**：统一迁移器与新进程的启动回执位置，避免程序已启动却一直提示未确认就绪；失败仍恢复原入口。
- **修复重启后多出额度周期**：同一截止窗口下，不再单凭旧重置提示切分周期；按保留的原始记录重新计算，避免观察量和推测总量从头开始。
- **托盘额度环与全屏让位**：托盘使用无数字纯圆额度环，亮色表示剩余，悬停查看简要额度信息。桌宠所在屏幕的游戏或视频全屏时可隐藏人物及面板，完成提醒不抢回显示；离开全屏后恢复原显示偏好。全屏识别仍有平台差异。
- **保留托盘常驻选择**：升级继承上一版本的常驻偏好，旧通知图标复用主身份并安全退休已核实的旧记录；Windows 设置中的历史列表缓存仍可能残留，不能保证立即清空。
- **改善窗口交接**：补齐正常卡片与大卡片切换的首帧保护，减少交接空白；尚不能保证所有驱动、多屏及休眠恢复场景都没有闪烁。

## 下载和升级

这是累计程序补丁，包含此前程序更新，只需最新一份。已有设置、统计、高清偏好和有效动画继续复用；本次不上传动画资源。

- 已安装用户：使用软件内更新；`program.zip` 与 `program.json` 供更新器使用，不要直接覆盖安装目录。
- 首次安装或需要安装器：使用仍有效的 [1.1.0 程序补丁安装器](https://github.com/Wunsch2048/codex-bailong-desktop-pet/releases/tag/v1.1.0)，安装后在软件内更新到 1.2.0。安装器不含动画，人物资源可在设置中下载。

本次仅发布程序 ZIP、更新描述、校验清单与演示动图，不重复上传完整安装器。程序和动画迁移仍需用户主动选择目标；升级不自动搬动实际目录。
